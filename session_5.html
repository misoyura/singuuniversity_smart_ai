01AI 윤리

AI가 사람과 사회에 미치는 영향을 고려하여 안전하고 공정하게 AI를 개발하고 사용하는 것입니다.

가치확인 질문
사람 권리 보호AI가 내 동의 없이 얼굴·목소리를 학습하지 않는가?
공정 · 차별 최소화같은 조건인데 성별·나이에 따라 다른 결과가 나오지 않는가?
안전 · 위험 관리AI가 잘못된 정보를 확신에 찬 어조로 말하지 않는가?
책임 · 인간의 최종 판단AI 결과를 쓰기 전 사람이 한 번 더 확인했는가?
⚠ AI도 편향될 수 있다 — Garbage In → Garbage Out 사례: 스캐터랩 AI 챗봇 '이루다' 논란 (2020.12~2021.01)
카카오톡 대화 데이터를 학습해 만든 챗봇 '이루다'가 서비스 3주 만에 성소수자·장애인 등에 대한 차별·혐오 발언을 하고, 실제 이용자의 개인정보가 노출될 위험이 드러나 서비스가 중단된 사례입니다. 데이터 편향과 개인정보 처리 문제가 동시에 불거진 국내 대표 사례로 다수 언론에 보도되었습니다.

AI 기술 → 사회적 영향 → 윤리적 문제 → 법·제도. AI가 사회에 미치는 영향이 커질수록 윤리만으로는 부족해집니다.

03Vibe Coding

"코딩을 몰라도 AI 서비스를 만들 수 있을까?" — 자연어로 원하는 결과를 설명하고 AI가 코드를 생성하도록 하는 방식입니다.

📌 Vibe Coding이란 아이디어 → 자연어로 설명 → AI가 코드 생성 → 실행 → 수정 요청 → 완성. '바이브(Vibe)' — 정확한 문법이 아니라 '이런 느낌'으로 설명해도 AI가 알아듣고 코드를 만든다는 뜻에서 붙은 이름입니다.
구분기존 코딩Vibe Coding
방식문법 학습 → 코드를 한 줄씩 작성아이디어 → AI에게 설명, 한국어 한 문장만 입력
환경VS Code · 터미널 필요브라우저만 있으면 OK
소요 시간완성까지 며칠~몇 주3~10분이면 작동
누가개발자만 가능비개발자도 가능
💡 핵심 코딩 능력보다 요구사항을 설명하는 능력이 중요해집니다. 단, 결과물의 품질(보안·개인정보 처리 등)은 여전히 사람이 확인해야 합니다 — '몰라도 시작할 수 있다'는 뜻입니다.

aistudio.google.com — Google 계정으로 바로 시작, 브라우저만 있으면 별도 설치 없이 한 문장으로 앱을 만들 수 있습니다.

실습 1 · 기억력 장보기 게임 프롬프트
기억력 장보기 게임 만들어줘.
- 총 10문제 (1~5번은 1개, 6~10번은 2개 기억)
- 기억할 아이템을 1초 보여주고 사라짐
- 16개 장보기 품목(사과·바나나·우유 등)이 4×4로
  나타나면 클릭해서 정답 맞히기
- 정답·오답 표시 후 1초 뒤 자동으로 다음 문제
- 끝나면 점수 + 「다시 하기」 버튼
이어서 · 디자인 수정 프롬프트
배경을 진하게, 아이콘과 글씨는 조금더 크게,
애니메이션 스타일, 입체적인 그리드 형식으로 만들어줘

04실습 · AI 윤리 자가진단 웹앱 만들기

"AI를 만들면서 AI 윤리를 직접 적용해본다." 이번 실습은 ChatGPT의 Canvas 기능으로 진행합니다 — chatgpt.com 접속 → 새 대화 → 프롬프트 입력 → 오른쪽 Canvas 창에서 코드/미리보기 확인.

STEP 1 · 기본 웹앱 만들기

실행 후 확인할 것: ☑ 질문 5개가 정상적으로 보이는가? ☑ 답변 선택 시 점수가 계산되는가? ☑ 모바일 화면에서도 깨지지 않는가?

실습 2 · 기본 웹앱 프롬프트
대학생을 위한 AI 윤리 자가진단 웹앱을 만들어줘.
5개의 질문에 답하면 AI 윤리 점수를 계산하고
결과에 따라 "안전하게 사용하세요" / "추가 확인이 필요합니다"
등의 메시지를 보여줘.
깔끔하고 직관적인 디자인으로 만들고
PC와 모바일에서 모두 사용할 수 있게 해줘

STEP 2 · 실행하고 확인하기

PROMPT → CODE → RUN → CHECK → FIX → RUN AGAIN. 첫 결과가 완벽하지 않아도 괜찮습니다. AI와 대화하면서 개선합니다.

실습 3 · 수정 요청 예시
"버튼 색깔이 잘 안 보여. 좀 더 눈에 띄는 색으로 바꿔줘."
"질문과 질문 사이에 여백을 좀 더 넣어줘."
"점수 결과가 나올 때 애니메이션 효과를 추가해줘."
"질문마다 간단한 설명을 한 줄씩 추가해줘."

STEP 3 · 윤리 기능 추가

이 5가지 항목은 앞서 본 'AI 윤리 5가지 체크'와 같은 축입니다 — 이론을 코드 기능으로 옮기는 과정입니다. (설명이 어렵다면 "대학 신입생도 이해할 수 있게 더 쉬운 표현으로 바꿔줘"라고 이어서 요청하세요.)

실습 4 · 윤리 점검 기능 추가 프롬프트
현재 웹앱에 AI 윤리 점검 기능을 추가해줘.
다음 5가지 항목을 각각 점검하도록 해줘.
1. 개인정보  2. 허위정보 가능성  3. 편향과 차별
4. 저작권  5. AI 생성물 표시

각 항목의 결과를 "주의 필요 / 확인 필요 / 문제 없음" 형태로
보여주고, 이해하기 쉬운 설명도 함께 보여줘.

STEP 4 · 내가 만든 AI 검증하기

📌 최종 점검 체크리스트 ☐ 개인정보를 요구하지 않는가? ☐ 잘못된 정보를 제공할 가능성은 없는가? ☐ 차별적인 판단을 하지 않는가? ☐ AI 생성물 표시가 필요한 경우 고려했는가? ☐ 사용자가 결과를 무조건 믿도록 만들지 않았는가? ☐ 사람이 최종적으로 확인할 수 있는가?

AI가 만든 결과도 사람이 검증해야 합니다.

실습 5 · 검증 안내 문구 추가 프롬프트
"이 진단은 참고용이며, 최종 판단은 사용자 본인이 해야 한다"는
안내 문구를 눈에 띄게 추가해줘.

05마무리

⚠ 가장 중요한 질문 — AI에게 윤리를 맡겨도 될까? NO. AI → 결과 생성 / 사람 → 판단 → 검증 → 책임. AI는 판단을 도울 수 있지만 책임까지 대신할 수는 없습니다. (오프닝에서 던졌던 "책임은 누가 지는가?"라는 질문의 답이 바로 이것입니다.)
  1. KNOWAI를 이해하고
  2. USEAI를 활용하고
  3. CREATEAI와 함께 만들고
  4. OWN그 결과를 책임진다
💡 오늘의 한 문장 AI에게 만드는 것을 맡길 수는 있지만, 책임까지 맡길 수는 없습니다. AI를 잘 쓰는 사람에서, 책임 있게 쓰는 사람으로.

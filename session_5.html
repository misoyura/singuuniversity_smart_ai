01AI 윤리

AI가 사람과 사회에 미치는 영향을 고려하여 안전하고 공정하게 AI를 개발하고 사용하는 것입니다.

AI가 항상 공정할까? — AI도 편향될 수 있다

AI에게 학습된 데이터 → AI의 판단. Garbage In → Garbage Out

⚠ CASE · 스캐터랩 AI 챗봇 '이루다' 논란 (2020.12~2021.01) 카카오톡 대화 데이터를 학습해 만든 챗봇 '이루다'가 서비스 3주 만에 성소수자·장애인 등에 대한 차별·혐오 발언을 하고, 실제 이용자의 개인정보가 노출될 위험이 드러나 서비스가 중단된 사례입니다. 데이터 편향과 개인정보 처리 문제가 동시에 불거진 국내 대표 사례로 다수 언론에 보도되었습니다.
이루다 1.0은 개인정보 침해 문제로 서비스가 중단되었고, 2.0이 현재 서비스 중입니다.

AI 기본법 Q&A — 핵심만 간단하게 알아보는 인공지능기본법

출처: 과학기술정보통신부 카드뉴스 (7문항)

질문답변
1. 인공지능기본법 적용 대상은 누구인가요? '인공지능사업자'입니다.
인공지능개발사업자 — AI를 개발·제공하는 자 (예: OpenAI(GPT-5.2), Google(Gemini 3.0), NAVER(HyperCLOVA X THINK/SEED/OMNI))
인공지능이용사업자 — 개발된 AI를 이용해 제품·서비스를 제공하는 자 (예: 자율주행 자동차, 생성형 AI 서비스, 컨텐츠 추천 AI 서비스)
※ 인공지능개발사업자가 직접 AI 제품/서비스를 이용자에게 제공하는 경우 인공지능이용사업자에도 해당할 수 있습니다.
2. 표시 의무는 누가 지켜야 하나요? '인공지능사업자'입니다. 이용자에겐 의무가 없습니다.
투명성 확보 의무 있음 — 인공지능개발사업자(예: Gemini · Nano Banana): 기반 모델 개발/제공 · 인공지능이용사업자(예: carat): 모델을 이용하여 AI 서비스 제공
투명성 확보 의무 없음 — 이용자(예: 방송사·유튜버): 생성된 콘텐츠 활용 및 방영 · 시청자·소비자: 콘텐츠 소비 및 시청
3. 인공지능사업자가 아니면 모든 책임에서 자유롭나요? 인공지능기본법상 책임만 면제일 뿐, 다른 법률은 준수해야 합니다 (정보통신망법, 공직선거법, 청소년성보호법, 표시광고법 등).
예시: 생성형 AI로 제작한 명예훼손 가능성이 있는 영상 유포 = 정보통신망법 위반에 따른 형사상 책임 발생 가능 · 생성형 AI로 제작한 기능 오인 가능성이 있는 광고 유포 = 표시광고법 위반에 따른 형사상 책임 발생 가능
4. 유튜버나 개인 창작자도 대상인가요? AI 생성물을 활용하는 크리에이터는 인공지능기본법상 '이용자'로 표시 의무가 없습니다.
5. 분야별 표시 의무 예시를 좀 알려주세요 방송·언론·출판 — 이미지/영상 생성 서비스를 제공하는 인공지능사업자는 의무 있음 (생성물을 이용하여 콘텐츠를 제작하는 방송사 등은 의무 없음)
콘텐츠·미디어 — 웹툰 제작 AI 서비스를 제공하는 인공지능사업자는 의무 있음 (이를 활용하는 웹툰 작가 등은 의무 없음)
교육·법률·의료·통번역 — 법률 지원 AI 서비스를 제공하는 인공지능사업자는 의무 있음 (이를 활용하는 법무법인 등은 의무 없음)
금융·행정·제조 — 업무 지원 AI 서비스를 제공하는 인공지능사업자는 의무 있음 (이를 활용하는 기관/기업 등은 의무 없음)
6. 인공지능기본법을 위반하면 어떻게 되나요? 사실조사 및 과태료 부과는 제도 안착을 위해 1년 이상 유예합니다 (2027. 1.). (유예기간은 1년 뒤 해외 동향과 기술 발전, 업계 준비 상황 등을 고려하여 추가 연장될 수 있습니다)
7. 스타트업을 운영 중인데 법 관련 도움을 받을 수 있을까요? 인공지능기본법 지원데스크 — 전화 080-850-2546 (평일 오전 9시 ~ 오후 6시) · sw.or.kr
기업의 인공지능기본법 관련 문의와 애로사항에 대해 컨설팅을 제공합니다. + 스타트업·지역기업 대상 현장 설명회 개최 (수요에 따라 수시로 개최)

03Vibe Coding

"코딩을 몰라도 AI 서비스를 만들 수 있을까?" — 자연어로 원하는 결과를 설명하고 AI가 코드를 생성하도록 하는 방식입니다.

📌 Vibe Coding이란 아이디어 → 자연어로 설명 → AI가 코드 생성 → 실행 → 수정 요청 → 완성. '바이브(Vibe)' — 정확한 문법이 아니라 '이런 느낌'으로 설명해도 AI가 알아듣고 코드를 만든다는 뜻에서 붙은 이름입니다.
도구설명
Gemini Canvas"쉽게 만들어서 바로 써보는 앱 제작 도구"
Google AI Studio"앱을 실제로 개발·발전시키는 바이브 코딩 도구"

기존 코딩 vs Vibe Coding

구분기존 코딩Vibe Coding
방식문법 학습 → 코드를 한 줄씩 작성아이디어 → AI에게 설명, 한국어 한 문장만 입력
환경VS Code · 터미널 필요브라우저만 있으면 OK
소요 시간완성까지 며칠~몇 주3~10분이면 작동
누가개발자만 가능비개발자도 가능
💡 핵심 코딩 능력보다 요구사항을 설명하는 능력이 중요해진다. 단, 결과물의 품질(보안·개인정보 처리 등)은 여전히 사람이 확인해야 합니다 — '몰라도 시작할 수 있다'는 뜻입니다.

실습 7 · 두더지 잡기 게임 (1단계)
HTML, CSS, JavaScript를 사용하여 웹 브라우저에서 바로 실행할 수 있는
두더지 잡기 게임을 만들어줘.

1. 게임 기본 구성
- 게임 화면은 한눈에 보기 좋은 중앙 정렬
- 화면 상단에 게임 제목 표시
- 점수 표시
- 남은 시간 표시
- 게임 시작 버튼 제공
- 게임판에는 3×3 형태로 총 9개의 구멍을 배치
- 게임이 시작되면 9개의 구멍 중 하나에서 두더지가 무작위로 나타남
- 사용자가 두더지를 클릭하면 점수가 올라감
- 두더지는 잠시 나타났다가 사라지고 다른 위치에서 다시 나타남

2. 게임 규칙
- 게임 시간은 30초
- 두더지를 클릭하면 +1점
- 두더지가 나타난 위치를 클릭하면 즉시 사라짐
- 두더지는 일정한 간격으로 무작위 위치에 등장
- 게임 시간이 0초가 되면 게임 종료
- 게임 종료 후 최종 점수를 보여줌
- 다시 시작 버튼으로 새로운 게임을 시작할 수 있도록 함

3. 화면 디자인
- 밝고 친근한 게임 분위기
- 어린이부터 성인까지 쉽게 사용할 수 있는 디자인
- 두더지는 귀엽고 재미있는 캐릭터 형태
- 구멍은 둥근 형태로 표현
- 버튼은 크고 눈에 잘 띄게 제작
- 점수와 시간은 게임 중 쉽게 확인할 수 있도록 크게 표시
- 모바일과 PC에서 모두 사용할 수 있도록 반응형으로 제작

4. 사용자 경험
게임을 처음 실행했을 때는 시작 버튼을 보여준다.
"게임 시작" 버튼을 누르면 카운트다운 없이 바로 게임이 시작된다.
두더지를 클릭할 때마다 시각적인 반응이 나타나도록 한다.
게임이 끝나면 다음 내용을 보여준다.
"게임 종료!"
"최종 점수: ○○점"
그리고 "다시 하기" 버튼을 제공한다.

5. 기술 조건
- HTML, CSS, JavaScript로 구현
- 별도의 서버 없이 브라우저에서 실행 가능하도록 제작
- 외부 라이브러리는 가능하면 사용하지 않음
- 게임의 핵심 기능이 정상적으로 작동하는지 확인
- 버튼, 점수, 타이머, 두더지 등장, 게임 종료 기능을 모두 실제로 작동하도록 구현

6. 중요
먼저 기능이 제대로 작동하는 것을 가장 중요하게 생각한다.
코드를 작성한 후 다음 항목을 스스로 점검해줘.
- 게임 시작 버튼이 정상적으로 작동하는가?
- 타이머가 30초부터 정상적으로 감소하는가?
- 두더지가 무작위 위치에 나타나는가?
- 두더지를 클릭하면 점수가 올라가는가?
- 게임 종료가 정상적으로 되는가?
- 다시 하기 버튼이 정상적으로 작동하는가?
- PC와 모바일 화면에서 게임판이 깨지지 않는가?
문제가 발견되면 직접 수정한 후 최종적으로 실행 가능한 상태로 완성해줘.

이미지 생성 AI의 흐름

과정특징예시
머신러닝사람이 규칙을 직접 설계, 특징 추출스팸 필터, 초기 얼굴 인식
딥러닝데이터에서 특징을 자동 학습(CNN/RNN 등장)음성인식, 스마트렌즈 초기 버전
GAN진짜 같은 이미지를 생성하는 첫 단계, 스타일 변환·합성딥페이크, FaceApp
Diffusion노이즈 제거 방식 이미지 생성미드저니, 스테이블 디퓨전, DALL-E
멀티모달언어모델의 '세상 지식과 추론력'이 이미지 생성에 그대로 연결나노바나나, GPT-Image
📌 GAN 모델 생성자(Generator) vs 판별자(Discriminator) — 생성자가 만든 가짜 이미지를 판별자가 진짜와 구분하며, 두 신경망이 서로 경쟁하듯 학습해 점점 더 정교한 이미지를 만들어냅니다.
📌 Diffusion 모델 노이즈(잡음)를 입힌 이미지에서 거꾸로 노이즈를 제거해 나가며 원하는 이미지를 점진적으로 복원하는 방식입니다. (원본 → 조금씩 흐리게 → 완전한 잡음 → 거꾸로 복원)
💡 멀티모달 통합형 모델 GPT-Image, Nanobanana — 언어모델의 지식과 추론력이 이미지 생성에 그대로 연결되는 최신 방식입니다.

프롬프트 입력방식 비교 — 최신 방식

방식설명
기존 방식파라미터를 따로 명시 (-- 방식은 미드저니 방식)
최신 방식일반적인 자연어 설명 방식 — 파라미터도 문장으로 풀어서 설명
📌 예시 (최신 방식) "한국의 조용한 골목길에 복슬복슬한 치즈 고양이가 앉아 있는 모습을 사실적인 사진 스타일로 생성해 주세요. 따뜻한 노을빛이 고양이의 털을 부드럽게 비추고, 맑고 반짝이는 눈과 섬세한 털 질감이 잘 표현되도록 해주세요. 영화 같은 구도와 85mm 카메라로 촬영한 듯한 얕은 심도를 적용하고, 배경은 자연스럽게 흐려져 고양이가 돋보이도록 해주세요. 세로 3:4 비율의 초고해상도 이미지로 만들어 주세요."

단계질문내용

② 구도와 조명어떻게 찍을 것인가?카메라 시점(클로즈업·조감도 등), 조명(노을·네온 등 빛의 연출)

03GPT Image 2.0 핵심 특징과 실습

업계 최초 '추론(Thinking)' 내장 이미지 모델 — 생성 전에 스스로 구조를 계획하고 검증합니다.

특징내용
추론(Thinking) 내장생성 전에 스스로 구조를 계획 및 검증, 텍스트 렌더링 정확도 대폭 향상
웹검색 연동실시간 사실 확인 후 이미지 생성 가능
공간관계와 논리 이해사물의 배치, 위치 관계를 정확히 반영
캐릭터 일관성여러 컷에서 동일 인물의 얼굴·복장을 유지
기존 이미지 편집원본 인물의 동일성은 유지하면서 구도·자세·의상을 새로 생성
상식과 문맥 이해시대·상황에 맞는 사실적 표현 + 유머러스한 재해석
텍스트 렌더링인포그래픽 등 이미지 안 문구를 정확하게 표현
이미지 분할 생성단계별 설명을 여러 장의 이미지로 나눠 생성

실습 3 · 공간관계와 논리 이해

배치 지정 프롬프트
책상 위에 노트북, 커피잔, 화분이 있는 사무실 사진.
노트북은 왼쪽, 커피잔은 노트북 오른쪽 뒤, 화분은 오른쪽 끝에 배치.
커피잔 옆에는 '월요일도 화이팅'이라고 적힌 메모지를 놓아줘.

실습 4 · 캐릭터 일관성 (웹툰 4컷)

동일 인물 4컷 프롬프트
웹툰형 4컷 이미지로 만들어줘. 주인공은 둥근 안경, 짧은 검은 머리,
파란색 넥타이, 회색 정장을 입은 30대 한국인 남성 공무원 김대리야.
네 장면 모두 동일 인물로 유지해줘.

1컷: 출근하며 자신감 있게 사무실 문을 연다.
2컷: 책상 위 산더미 같은 서류를 보고 얼어붙는다.
3컷: 생성형 AI를 사용해 서류를 빠르게 정리한다.
4컷: 정시에 퇴근하며 뒤쪽 동료들에게 손을 흔든다.

각 컷에서 얼굴, 안경, 헤어스타일, 넥타이와 정장 색상을 동일하게 유지해줘.

실습 5 · 상식과 문맥 이해

시대·상황 재해석 프롬프트
조선시대 관아에서 운영하는 스마트 민원실을 영화 스틸컷처럼
사실적으로 만들어줘. 한복을 입은 백성이 나무로 된 번호표
발급기에서 번호표를 뽑고, 갓을 쓴 관리가 붓 대신 태블릿으로
민원을 처리하고 있어. 벽에는 한지로 만든 대형 전광판이 있고,
전광판에는 "대기번호 21번"이라고 적혀 있어. 구석에는 작은
로봇이 두루마리 문서를 자동으로 분류하고, 밖에는 말 대신
전기 가마가 충전 중이야. 조선시대 건축, 의복, 가구는
사실적으로 표현하되, 현대 기술은 조선시대 재료로 재해석해줘.
유머러스하지만 고급스럽고 영화적인 분위기, 16:9.

01AI 이해

AI(Artificial Intelligence, 인공지능)란 무엇일까요?

  1. 데이터많은 양의 자료를 모읍니다
  2. 학습자료 속 규칙을 익힙니다
  3. 패턴반복되는 구조를 찾습니다
  4. 판단 · 생성새로운 상황에 답을 냅니다
📌 AI란 인간의 지적 활동을 컴퓨터가 수행하도록 만든 기술입니다.

생성형 AI는 무엇이 다를까요?

구분하는 일
기존 AI분류 · 예측 · 판단
생성형 AI텍스트 · 이미지 · 음성 · 영상 생성 — 새로운 결과물을 만들어냅니다

검색엔진 vs 생성형 AI

구분하는 일비유
검색엔진정보를 찾는다 — 이미 있는 자료 목록을 보여줍니다도서관 사서
생성형 AI결과를 생성한다 — 내 상황에 맞는 결과물을 만들어 줍니다나의 AI 비서
⚠ AI는 똑똑하지만 항상 맞지는 않습니다 AI 결과 ≠ 항상 정답 — 환각(그럴듯한 거짓을 만들어냄), 오류(숫자와 사실을 틀림), 오래된 정보(최신 내용이 아닐 수 있음). "AI가 자신 있게 말하면 사실일 가능성이 높다" → X, 자신감과 정확도는 별개입니다.

03프롬프트 최적화 기법

왜 AI에게 원하는 답이 나오지 않을까요? "광고 문구 써줘"처럼 짧은 요청은 너무 평범한 결과를 낳습니다. AI가 못해서가 아니라 설명이 부족했을 수 있습니다.

📌 프롬프트란 Prompt = AI에게 주는 지시문. 무엇을, 어떻게, 어떤 형태로 해달라고 말해주는 문장입니다. ("이런 일을 이렇게 해줘"라고 업무를 부탁하는 것과 같습니다.)

UPDATE · 프롬프트 작성법이 바뀌었습니다

구분구성 요소
OLD 공식
5요소 · 매번 채움		ROLE(역할) · GOAL(목표) · CONTEXT(맥락) · CONSTRAINT(조건) · OUTPUT(출력)
NEW 공식
기본 4 + 선택 3		기본: CONTEXT(맥락) · INSTRUCTION(지시) · FORMAT(형식) · AUDIENCE(대상)
선택(필요할 때만): ROLE · EXAMPLE · CONSTRAINT
💡 핵심 "역할을 매번 넣는 것"보다 "상황과 대상"을 정확히 주는 것이 중요해졌습니다.

선택 요소, 언제 추가할까?

② 실습 2 · 홍보 콘텐츠 프롬프트 (실전 예시)

CONTEXT + INSTRUCTION + FORMAT + AUDIENCE 순서로 맥락을 알려주고 → 원하는 결과를 지시하고 → 형식을 정하고 → 대상을 알려주는 실제 프롬프트입니다.

실습 2 · 홍보 콘텐츠 프롬프트
실무자 대상 AI 엑셀 자동화 특강을 홍보할 SNS 콘텐츠가 필요해.
교육의 핵심 장점과 차별점을 강조하고, 신청으로 이어질 수 있도록
친근하고 설득력 있는 홍보 문구를 작성해줘.
인스타그램·네이버 블로그·카카오톡에 활용할 수 있도록 각각 작성하고,
이모지와 해시태그 3개를 포함해줘.
AI나 엑셀 자동화가 어렵게 느껴지는 20~40대 직장인과 실무자를 대상으로 작성해줘.
💡 핵심 포인트 정보가 구체적일수록 결과는 더 좋아집니다. 선택 3요소(ROLE·EXAMPLE·CONSTRAINT)는 필요한 경우에만 추가하세요.

GEM이란 — 나만의 맞춤형 AI 비서

반복되는 업무·질문을 미리 정한 역할과 규칙으로 저장해두는 기능입니다.

구분일반 챗GEM
특징매번 새 프롬프트 입력, 역할을 매번 다시 설명한 번 등록 → 클릭 호출, 역할·말투·형식 영구 저장
비유임시 직원 — 일회성정규직 — 부서 공유 가능

GEM 설계 5가지 질문

이 5가지가 곧 GEM의 시스템 프롬프트가 됩니다.

질문예시
1. 반복 작업 자동화 — 매번 하는 작업은?민원 답변 / 회의록 / 공문 초안
2. 맞춤형 지식 학습 — 참고 자료는?조례 · 매뉴얼 · 이전 답변 사례
3. 고정 형식 — 결과물 형식이 있나?공문서 양식 · 표 · 개조식
4. 톤앤매너 — 꼭 지킬 말투는?공문서체 · 친절 답변체 · 보고체
5. 금지 정보 — 출력하면 안 되는 정보는?개인정보 · 미확정 수치 · 대외비

실습 4 · GEM 설계 프롬프트
당신은 구글 젬스(Gems) 설계 전문가입니다.

출력 형식은 반드시 아래 예시처럼 작성하세요.

[출력 형식 예시]
■ 젬 이름:

■ 젬 지침
페르소나:

[작성 규칙]
1. 젬 이름 — 주제의 핵심 기능이나 특징이 직관적으로 드러나는 매력적인 제목을 작성하세요.
2. 설명 — 이 Gem이 어떤 역할을 하는지 1~2문장으로 간결하게 설명하세요.
3. 페르소나(Persona) — Gem이 어떤 역할과 말투로 대화할지 구체적으로 설명하세요.
4. 작업(Task) — Gem이 수행해야 할 일이나 사용자에게 제공할 도움을 명확히 제시하세요.
5. 관련 정보(Info) — Gem이 참고할 배경 정보나 입력값 예시를 포함하세요.
6. 형식(Format) — 결과물이 어떤 형태로 나와야 하는지 구체적으로 지정하세요.

[주제]
예) 국내여행 플래너 / 민원 응답 비서 / 회의록 정리 비서
⚠ 주의 GEM에 개인정보 · 미확정 수치 · 대외비를 다루게 할 경우, "출력하면 안 되는 정보"를 반드시 지침에 명시하세요.

06마무리

AI가 만든 결과, 그대로 사용해도 될까요? AI는 초안을 만들고, 사람은 완성합니다.

  1. AI 초안AI가 만든 첫 결과

AI를 잘 쓰는 사람의 5가지 원칙

원칙내용
1. 개인정보 보호이름 · 연락처 · 내부 자료는 넣지 않습니다
2. 사실 확인숫자와 출처는 직접 확인합니다
3. 저작권 확인공개하기 전에 권리를 확인합니다
4. 비판적 검토그럴듯한 문장일수록 한 번 더 의심합니다
5. 최종 판단은 사람책임은 AI가 아니라 사람이 집니다
📌 오늘 배운 것 이해(AI와 생성형 AI의 차이) · 질문(프롬프트 4+3요소) · 비교(세 가지 텍스트 AI) · 생성(홍보 콘텐츠와 GEM) · 검증(사실 확인과 최종 판단). AI는 도구입니다. 결과를 만드는 것은 그것을 다루는 사람입니다.

02Flow로 영상 만들기

글, 이미지, 영상 제작 과정을 '흐름(Flow)'으로 자동 연결해 주는 구글의 AI 도구입니다. 글(Text) → 이미지(Image) → 영상(Video) 순서로 한 화면에서 처리합니다.

구분내용
기능텍스트 → 영상 자동 생성, 상황에 맞는 이미지·장면 자동 배치, 음성·자막 자동 생성, 장면 단위 편집
장점영상 제작 진입장벽이 낮다, 제작 속도가 빠르다, 반복 생성이 쉽다, 안내·홍보 영상 활용도가 좋다
  1. 기획 입력만들고 싶은 영상의 주제와 장면을 텍스트로 입력합니다
  2. 장면 생성AI가 이미지와 장면을 자동으로 구성합니다
  3. 편집 완성음성·자막을 더하고 장면을 이어 붙여 완성합니다

Flow 요금제와 크레딧

플랜크레딧특징
무료가입 시 150(100+50), 매일 50 추가이미지 하루 약 18장, Veo 3.1 핵심 기능 사용 가능
프로월 1,000영상 약 50개 생성, 비디오 확장·업스케일링 가능
울트라월 25,000고퀄리티 영상 대량 제작, 전문 워크플로우
📌 참고 영상 1개 생성 시 20 크레딧 소진, 이미지 생성은 크레딧 소진 없음. 구글(Gmail) 계정만 있으면 별도 프로그램 설치 없이 바로 시작할 수 있습니다.

실습 1 · 프롬프트로 이미지 생성하기

화면 하단 입력창에 원하는 이미지를 문장으로 설명합니다. 이미지 비율(16:9, 1:1, 9:16 등)과 생성 모델(Nano Banana Pro 등)을 먼저 선택하세요.

실습 1 · Flow 이미지 생성 프롬프트
개발도상국 농촌 마을에서 한국인 봉사단원과 현지 주민이
서로 웃으며 대화하는 장면, 진정성 있는 교감, 따뜻한 분위기,
흙길과 전통 가옥, 자연스러운 생활 환경 디테일,
부드러운 자연광(golden hour lighting), 다큐멘터리 사진 스타일,
ultra realistic, 4k, high detail

실습 2 · 참조 이미지로 나만의 장면 만들기

참조 이미지의 인물·캐릭터·분위기는 그대로 유지한 채, 프롬프트만 바꿔 새로운 장면을 만들 수 있습니다. 동일 캐릭터로 여러 장면을 일관되게 제작할 때 유용합니다.

실습 2 · 참조 이미지 + 프롬프트
핑크색 볼캡 모자를 쓴 모습을 그려줘

실습 3 · ChatGPT로 영상 프롬프트 설계하기

ChatGPT 등 텍스트 AI로 장면별 영상 프롬프트를 미리 구성하면 더 정교한 결과를 얻을 수 있습니다. 완성된 영어 프롬프트를 Flow 입력창에 그대로 붙여 넣어 사용합니다.

실습 3 · ChatGPT 영상 프롬프트 설계 요청
좋아! 이 5개의 각 장면을 'Flow'에서 영상으로 생성할 거야.
장면에 어울리는 프롬프트를 구성해 줘.
각 장면당 코드 블록으로 생성해 줘.
구글 정책에 위반되지 않는 단어와 내용으로 작성해 줘.
💡 영상 생성 실행 단계 ① 참조 이미지 추가 → ② 프롬프트 입력 → ③ 생성 옵션 설정(9:16, Veo 3.1) — 업스케일을 선택하면 추가 크레딧과 시간이 더 소요됩니다. 5개 장면을 모두 생성한 뒤 순서대로 이어 붙이면 짧은 영상이 완성됩니다.

03vStory로 숏폼 영상 만들기

AI와 함께 나만의 영상을 만드는 숏폼 제작 도구입니다. 앱 설치 없이, 로그인 없이도 제작과 다운로드가 가능합니다.

⚠ 주의 로그인하지 않으면 영상이 1일만 임시 저장됩니다. 영구 저장을 원한다면 로그인 후 사용해야 합니다.

실습 4 · vStory로 숏폼 완성하기

  1. 영상 스타일 선택하기원하는 숏폼 스타일을 고릅니다
  2. 재료 추가하기영상 재료가 될 사진·동영상을 추가합니다
  3. 프롬프트 입력원하는 결과를 채팅하듯 문장으로 입력합니다 (제미나이로 만든 스토리 내용을 복사해서 붙여넣어도 좋습니다)
  4. 전송오른쪽 하단의 전송 아이콘을 클릭하면 영상 생성이 시작됩니다
  5. 다운로드완성된 영상을 미리보기 후 다운로드하거나, 로그인 후 저장합니다

04SUNO로 음악 만들기

문장 하나로 오리지널 음악을 만들어 주는 AI 음악 생성기입니다. 구글 계정 등으로 간편하게 로그인하고, 가사와 곡 스타일을 직접 지정하거나 AI가 자동 생성하게 할 수 있습니다.

실습 5 · SUNO 곡 생성 (Simple)

만들고 싶은 곡을 문장으로 설명하면, AI가 가사와 음악을 함께 만들어 줍니다.

실습 5 · SUNO 곡 설명 프롬프트
밴드가 직접 연주하는 것 같은 록 음악.
기타 사운드가 시원하고 보컬은 힘 있으면서도 자연스럽다.
답답했던 기분이 뻥 뚫리는 느낌.
📌 Instrumental 옵션 ON — 가사 없이 연주만 있는 비트 중심 배경음악 스타일 · OFF — 가사가 있는 노래(보컬+가사) 스타일로 생성

실습 6 · SUNO 곡 생성 (Advanced) — 가사부터 직접 쓰기

내가 만든 가사를 그대로 살리고 싶다면 ChatGPT로 먼저 가사를 작성한 뒤, SUNO 가사 입력창에 붙여넣습니다.

① ChatGPT · 가사 작성 요청
트렌디한 감성의 한국어 노랫말을 작성해 줘.
주제: [잊혀진 사랑]
조건:
- AI처럼 설명하지 말고 장면과 행동으로 표현
- 흔한 사랑 표현은 줄이고 일상적인 이미지 활용
- 후렴은 짧고 기억에 남게
② ChatGPT · 스타일 프롬프트 작성 요청
위의 가사와 어울리는 suno 스타일 프롬프트를
800자 이내로 영어로 작성해 줘. 복사할 수 있게 제공해 줘.
💡 완성한 음악 다운로드하기 (MP4) 곡 목록에서 '⋯' 메뉴 → 다운로드 → Video 선택 → Upgrade 대신 download anyway 선택. Publish(공개) 상태로 전환하면 무료 플랜에서도 비디오 다운로드 메뉴가 열립니다. 직접 녹음한 멜로디나 목소리를 업로드해 AI가 곡을 확장하도록 만들 수도 있습니다.
⚠ SUNO 생성 음악의 저작권 무료 플랜으로 제작한 노래는 상업적 사용이 불가능합니다. 상업적으로 사용하려면 유료 플랜으로 제작(또는 무료 제작 후 유료로 전환)해야 합니다.
